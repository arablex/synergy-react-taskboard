# TaskBoard — итоговый проект курса «Библиотека React»

Приложение для ведения задач по спринтам (аналог Jira / Trello): рабочий стол со статистикой,
канбан-доска активного спринта с перетаскиванием задач и панель администратора с формами
создания задач, спринтов и участников.

Стек: React 19 + TypeScript, Vite, react-router-dom, SCSS (без UI-библиотек).
Данные хранятся в localStorage (при первом запуске подставляются демо-данные).

## Запуск

```
npm install
npm run dev          # http://localhost:5173
npm run build        # сборка в dist/ (tsc + vite build)
npm run preview      # просмотр собранной версии
npm run lint         # oxlint
```

## Страницы

| Маршрут   | Страница                              |
|-----------|---------------------------------------|
| `/`       | Рабочий стол (вкладки Product / Backlog, статистика, графики, «only my issues») |
| `/sprint` | Активный спринт — канбан-доска с drag-and-drop и фильтром по участникам |
| `/admin`  | Панель администратора — таблица задач, окна «Создать задачу», «Создать спринт», «Добавить участника» (`/admin?modal=task` открывает окно сразу) |

## Структура

```
src/
  components/
    board/     Board, TaskCard, TaskDetails — доска и карточки
    charts/    BurndownChart, StatusDonut, WorkloadBars — SVG-графики
    forms/     TaskForm, SprintForm, MemberForm — формы в модальных окнах
    ui/        переиспользуемые поля (TextField, TextArea, SelectField, DateField,
               CheckboxGroup, ReadOnlyField), Modal, Avatar, EstimateBadge
  hooks/useForm.ts   — хук формы: значения, ошибки, «тронутые» поля
  pages/             — DashboardPage, SprintPage, AdminPage
  store/             — состояние приложения (useReducer + Context), сохранение в localStorage
  utils/             — даты, формат времени (6ч / 1д.6ч), генерация ID (XX-1234), ёмкость спринта
  styles/            — SCSS: переменные, миксины адаптива, стили по разделам
  data/seed.ts       — демо-данные (команда, два спринта, 19 задач)
```

## Правила валидации

- Задача: заголовок, подзаголовок, автор, исполнитель, время выполнения (`6ч`, `1д.6ч`, `2д` или число часов, 1 ч — 20 д), описание не короче 40 символов; комментарий — если указан, тоже не короче 40 символов; ID вида `XX-1234` генерируется автоматически (буквы A–Z, цифры 1–9).
  Если выбран спринт, проверяется остаток времени исполнителя до конца спринта: нет времени — задачу создать нельзя, иначе показывается, сколько останется.
- Спринт: имя (уникальное), цель, даты начала и окончания (окончание не раньше начала, не больше 60 дней); длительность считается автоматически.
- Участник: ФИО (фамилия и имя буквами, без дублей), должность, подразделение.

## Адаптивность

ПК (> 1100 px) — 4 колонки доски, 2 колонки на рабочем столе; планшет (720–1100 px) — 2 колонки;
телефон (< 720 px) — одна колонка, меню переносится на вторую строку, таблицы прокручиваются по горизонтали.
